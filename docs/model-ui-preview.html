Temperature

Currently 0.1

  • Input range 0–2. Controls randomness when choosing the next token. Lower values make choices more predictable; higher values make them more varied.

Top-p

Currently provider default

  • Input range 0–1. Limits choices to the smallest set of tokens whose combined probability reaches this value. Lower values narrow the choices; 1 keeps the full set.

Frequency penalty

Currently provider default

  • Input range -2–2. Adjusts repetition based on how often a token has already appeared. Positive values discourage frequent repeats; negative values encourage them.

Presence penalty

Currently provider default

  • Input range -2–2. Adjusts repetition based on whether a token has appeared at all. Positive values encourage new wording or topics; negative values favor reuse.
